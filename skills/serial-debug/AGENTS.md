# Agent skills

## Issue tracker

创建、读取或发布规格与任务时，使用本仓库 GitHub Issues；操作约定见 [issue tracker](docs/agents/issue-tracker.md)。

## Triage labels

分类或领取 issue 时，使用 [triage labels](docs/agents/triage-labels.md) 中的五种默认角色映射。

## Domain docs

设计或实施前，按 [domain docs](docs/agents/domain.md) 读取适用的术语与架构决策；本仓库采用单一领域文档结构。

## Progress

接续项目工作时，先读取 `progress/progress.md` 当前概况并核对工作区状态；只有缺少细节时再读取链接的交接记录。实质进度变化时更新当前概况；用户请求 handoff 时保存交接记录并更新索引，保留 handoff 技能的手动调用约定。
