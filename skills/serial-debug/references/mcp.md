# MCP Usage

Use MCP only when the user already has a serial MCP client configured or explicitly wants MCP tool usage.

The shared-console Conserver workflow is the default for this skill.
Use MCP only if you are intentionally bypassing the shared console and talking to serial tooling directly.

Keep the same evidence rules:

- report the actual console or port name
- report actual output or error text
- do not infer that hardware changed state without proof
