# Domain docs

本仓库采用 single-context：根目录 `CONTEXT.md` 保存领域术语，`docs/adr/` 保存架构决策。

## 读取规则

- 探索或实施前，若存在 `CONTEXT.md`，先读取与当前任务有关的术语。
- 若存在 `docs/adr/`，读取与改动有关的决策；若需求与决策冲突，明确指出冲突及影响。
- 文档不存在时继续工作，不创建空白领域文档或空 ADR 目录。
- 规格、测试和实现保持术语一致；新增术语在实际领域建模时记录，不为初始化复制整份规格。

功能规格与任务以 [GitHub Issues](issue-tracker.md) 为权威来源。
